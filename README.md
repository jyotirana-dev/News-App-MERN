# News App MERN

A full-stack news application built using MERN stack.

## Features

- User Authentication with JWT
- Admin based authorization
- Create, Update, Delete News
- Image and Video Upload
- Cloudinary Integration
- Multer File Handling
- Error Handling
- MongoDB Database

## Tech Stack

Frontend:
- React.js
- React Router
- Context API
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
